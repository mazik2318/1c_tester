# 1С:Профессионал — тренажёр

Веб-приложение для подготовки к аттестации **1С:Профессионал по платформе «1С:Предприятие 8.3»**.

## Возможности

- **961 вопрос** по **14 разделам**
- **Режим экзамена** — 14 вопросов (по одному из каждого раздела)
- **Изучение по разделам** — прохождение вопросов по порядку
- **Случайные вопросы** — 20 случайных из всей базы
- Прогресс сохраняется в браузере
- Работает офлайн (PWA)
- Адаптировано под iPhone / Android

## Как развернуть на GitHub Pages

1. Создай новый репозиторий (или используй существующий)
2. Загрузи все файлы из этой папки в корень репозитория:
   - `index.html`
   - `questions.json`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. В настройках репозитория → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `/ (root)`
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ТВОЙ_USERNAME.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## Добавить на домашний экран iPhone

1. Открой сайт в **Safari**
2. Нажми кнопку «Поделиться» (квадрат со стрелкой)
3. Выбери **«На экран „Домой“»**
4. Готово — приложение появится как обычная иконка

## Локальный запуск

Просто открой `index.html` в браузере, или подними локальный сервер:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```
